Hardware

Networking

The network is the foundation everything else runs on. We default to open hardware you fully control — and we're upfront about where that approach has real limits.

← All services

Default: open-source router + wired access points

We build on GL.iNet hardware (the Flint family) — built on OpenWrt, no cloud account required, WireGuard/OpenVPN built in, full root/SSH access if you want it. One Flint unit covers most single-router homes.

For homes that need multiple access points, we add additional GL.iNet units in AP mode over wired backhaul, with roaming configured manually using 802.11k/v/r fast-roaming standards.

Worth knowing: GL.iNet doesn't yet offer plug-and-play mesh — there's no "add a node in an app" step. We configure roaming professionally as part of install, but we won't market it as consumer mesh, because it isn't.

Fallback: self-hosted UniFi mesh

If your home layout makes wired backhaul impractical — finished walls, a detached garage or shop — or you specifically want zero-touch wireless mesh roaming, we'll build on a self-hosted UniFi controller instead. No mandatory cloud dependency, but closed-source and locked to UniFi hardware.

This is genuinely the only option in our lineup for true wireless-backhaul mesh, and we'd rather tell you that upfront than oversell GL.iNet roaming as something it isn't.
